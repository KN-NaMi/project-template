# Project Template

Multi-disciplinary project template for electronics, mechanics, and software development.

## 📁 Structure

```
project-template/
├── README.md                 # Project overview
├── bom.csv                   # Bill of Materials
├── electronics/              # Electronics
├── mechanics/                # Mechanical
└── software/                 # Software
```

## 🚀 Quick Start

1. Clone this template for your new project
2. Customize folder names and content
3. Add your design files and code
4. Update README files with project details

## 📋 Features

- **Electronics** - PCB design, simulations
- **Mechanics** - CAD files, drawings, 3D printing
- **Software** - Apps, firmware, scripts
