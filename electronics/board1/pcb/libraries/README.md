# Libraries

This directory contains custom component libraries used in PCB designs for the project. Each library includes schematic symbols and PCB footprints.

## 📁 Content
- **Schematic Symbols**: Custom symbols for components used in schematics
    - `board1.kicad_sym`
- **PCB Footprints**: Physical layouts for components to be placed on the PCB
    - `board1.pretty`
- **3D Models**: 3D representations of components for visualization
    - `3D_models/`
